# Yooka & Laylee — Sonic & SEGA All-Stars Racing Mashup

Status: design/preflight scaffold only; no playable host-game build yet.

Host game: Sonic & SEGA All-Stars Racing (PC). The player selects Yooka & Laylee as one combined racer: Yooka drives, Laylee rides along. Version 1 targets solo racing, a custom jungle-themed kart, menu presentation, race animations, themed audio/effects, and a custom All-Star move.

The JSON files in `sheets/` are the source of truth. `tools/preflight.py` blocks a build while required cells are unverified or references do not resolve.

No original game files, decompiled game code, credentials, or third-party copyrighted assets are included here.
